# 아키텍처 결정 기록(ADR)

ADR(Architecture Decision Record)은 중요한 설계 선택과 그 이유를 짧게 남기는 문서입니다. 코드가 바뀌었을 때도 “왜 이 방식으로 만들었는지”를 빠르게 확인할 수 있습니다.

| 번호 | 결정 | 상태 |
| --- | --- | --- |
| [0001](0001-scope-and-research-boundary.md) | 선택한 법령 도메인의 인용 기반 조사 지원으로 서비스 범위 제한 | 채택 |
| [0002](0002-evidence-and-citation-gate.md) | 답변 전에 근거와 인용을 검증 | 채택 |
| [0003](0003-versioned-local-source-ingestion.md) | 버전이 기록된 로컬 원본에서 법령 적재 | 채택 |

새 ADR은 `NNNN-짧은-제목.md` 형식으로 추가합니다. 각 문서에는 상황, 결정, 결과를 간단히 기록합니다.
